# CC105 Terminal Assessment 2 — BSIT 2.4
University Student Service & Queue System

Members: Maguigad, William; Protacio, Santino Adelrey; Artista, Ashanti P.


## Build and run (VS Code / Windows PowerShell)
```powershell
g++ -std=c++17 -O2 -Wall -Wextra -Wpedantic main.cpp -o student_service.exe
.\student_service.exe
```
Run inside the folder containing `main.cpp`.

## Features
Doubly linked registry; linked undo stack; FIFO and priority queues; linear and binary searching; bubble, selection and insertion sorting by ID, name and priority; benchmark across 100, 1,000, 10,000 and 50,000 generated items.
